# 英语口语练习小程序（uni-app）

这是一个基于 **uni-app** 架构的英语口语练习小程序示例，满足以下要求：

- 页面全部使用中文。
- 用户交互提示全部使用中文。

## 页面说明

1. **首页**：展示学习建议，并可快速进入练习。
2. **每日练习**：展示英语练习句，并提供中文生成建议互动。
3. **情景对话**：提供餐厅、机场等常见场景的中文引导练习。
4. **学习中心**：展示学习数据和中文提醒开关。

## 运行方式

1. 使用 HBuilderX 导入 `miniapps/english-speaking-uniapp`。
2. 选择运行到微信开发者工具或浏览器（H5）。
3. 如需发布微信小程序，请在 `manifest.json` 中配置 `mp-weixin.appid`。
